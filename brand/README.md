# DOMParity brand files

From the logo designed with Gemini (source/final-*.jpeg), traced to flat vector
paths with `python3 trace.py` (needs Pillow and potrace) and filled with the exact
brand colors. All files have a transparent background.

| File | Use |
|---|---|
| domparity-logo-light.svg | logo on light backgrounds |
| domparity-logo-dark.svg | logo on dark backgrounds |
| domparity-symbol.svg / -dark.svg | symbol alone |
| favicon.svg, favicon.ico | browser tab icon |
| png/ | PNG exports (logo 600/1200/2400 px, symbol 256/512/1024 px, favicon 16-512 px) |

Colors: indigo #4F46E5, teal #14B8A6, navy #1E1B4B; on dark backgrounds
indigo #818CF8, teal #2DD4BF, text #F8FAFC.
